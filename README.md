## 📖 About TgProxies

**TgProxies** is a community project dedicated to sharing proxy configurations, VPN client downloads, and connection guides.

Our goal is to organize configurations by protocol and make them easier to access, import, and maintain.

### 📥 How to Use Configurations

1. Open the configuration file for your preferred protocol.
2. Copy a configuration compatible with your client.
3. Open your VPN application.
4. Import the configuration or subscription URL.
5. Connect and test your connection.

⚠️ Configurations may expire or stop working. Availability, compatibility, and speed are not guaranteed.

## 🛠️ Configuration File Format

| File | Content |
|---|---|

| `config/vmess.txt` | VMess configuration links |
