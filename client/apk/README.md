## 📲 How to Install an APK

1. Open the official download link for your chosen application.
2. Select a release compatible with your Android device.
3. Download the APK file.
4. Open the downloaded file.
5. If prompted, allow your browser or file manager to install unknown apps.
6. Follow the installation instructions.
7. Open the application and import a compatible configuration.

⚠️ Only enable APK installation permissions for sources you trust. You can disable the permission again after installation.

## 🛠️ Troubleshooting

<details>
<summary><strong>APK installation failed</strong></summary>

- Verify that the APK is compatible with your Android version and device architecture.
- Check that enough storage space is available.
- Download the file again from the official release page.
- Check whether an existing installation is conflicting with the APK.

</details>

<details>
<summary><strong>The configuration cannot be imported</strong></summary>

- Verify that the configuration format is supported by your application.
- Make sure the configuration was copied completely.
- Try importing the configuration using the application's supported import method.
- Check whether the configuration has expired.

</details>

<details>
<summary><strong>The application connects but the internet does not work</strong></summary>

- Try another configuration.
- Check your device's internet connection.
- Verify the application permissions and VPN status.
- Remember that server availability and routing can change.

</details>
