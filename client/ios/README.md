## 📲 Installation Guide

1. Open the App Store link for your chosen application.
2. Check the app's compatibility, price, and availability in your region.
3. Install the application.
4. Open the application and use its supported import feature.
5. Import a compatible configuration from TgProxies.
6. Approve the iOS VPN configuration prompt if you trust the application.
7. Connect and test your internet connection.

> **Important:** iOS generally does not allow installing ordinary Android-style APK files. Install iOS applications through the App Store or another official distribution method supported by the developer.

## 🛠️ Troubleshooting

<details>
<summary><strong>The App Store says the app is unavailable</strong></summary>

- Check your Apple Account's country or region.
- Search for the application by name directly in the App Store.
- Confirm that the app is compatible with your iOS version.
- Use only distribution methods provided by the developer.

</details>

<details>
<summary><strong>The configuration cannot be imported</strong></summary>

- Check whether the application supports the protocol.
- Make sure the entire configuration link was copied.
- Try the application's clipboard, URL, QR code, or file import feature, as supported.
- Check whether the configuration has expired.

</details>

<details>
<summary><strong>iOS asks to add a VPN configuration</strong></summary>

This permission may be required for the app to route network traffic through a VPN interface. Only approve it if you trust the application and understand its purpose.

</details>

<details>
<summary><strong>The client connects but websites do not load</strong></summary>

- Try another configuration.
- Check whether the server is online.
- Verify the application's DNS and routing settings.
- Check whether another VPN or network filtering application is interfering.

</details>

## 🔒 Security Notice

- Install applications from official sources.
- Review app permissions and privacy policies.
- Do not share private keys, credentials, or personal subscription URLs publicly.
- A proxy does not guarantee complete anonymity or prevent all tracking.
- Avoid importing configuration files from sources you do not trust.
